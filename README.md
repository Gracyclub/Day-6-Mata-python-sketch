# 🌸 Day 6: Maa Katyayani - Cosmic Neon Particle Assembly 🚀

Welcome to Day 6 of the **Navratri Python Coding Series**!  
Today's project features a cinematic, cyber-cosmic visual simulation of **Maa Katyayani** built entirely using **Python**, **OpenCV**, and **NumPy**.

Instead of traditional line-drawing animations, this project renders an orbital energy portal where thousands of glowing neon particles swirl, react to gravity physics, and assemble into the divine neon form of Maa Katyayani against a deep space nebula background.

---

## ✨ Features
- **Orbital Energy Portal:** Real-time glowing energy vortex rendered using mathematical trigonometric waves.
- **Dynamic Gravity Physics:** Over 8,000+ custom stardust particles dynamically snapping to edge contours and color coordinates.
- **Cyber Glitch & HUD Telemetry:** Realistic real-time loading bar and telemetry animations.
- **Smooth Alpha Blending:** High-resolution transition from particle cloud to full neon artwork.
